# Setting up and using social media accounts

The downloaded images and videos can be posted directly from the program using the APIs of Twitter, Mastodon, and BlueSky, each with their own limitations.

These are the limitations of the available social networks:

Twitter: Maximum of 240 characters, four images or one video, and limited to about 30 posts per day with the free API tier.

Mastodon: Maximum of 5000 characters, four images or one video.

BlueSky: Maximum of 300 characters, one image or one video.

To use this feature, you need to register for the APIs of the networks you want to use.
